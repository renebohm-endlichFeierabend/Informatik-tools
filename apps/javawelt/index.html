So arbeitest du mit der JavaWelt

  1. Klassen schreiben: Unten im Quelltext-Bereich. Eigene Figuren-Klassen erben von Figur (public class Biene extends Figur { … }) – mehr Gerüst braucht es nicht.
  2. Übernehmen: ✓ Übernehmen übersetzt deine Klassen. Dabei wird die Welt geleert.
  3. Objekte platzieren: Bei einer Klasse auf neu tippen, dann auf die Welt tippen.
  4. Methoden aufrufen: Objekt antippen – rechts erscheinen seine Methoden mit Eingabefeldern.
  5. Spiel starten: ▶ Start führt deine Weltklasse aus: erst bereiteVor(), dann spiele() mit der Spielschleife while (laeuft()) { … warte(100); }. ■ Stopp beendet die Schleife.
  6. Bilder: Über den 🖼-Knopf bekommt eine Klasse ein Emoji oder eigenes Bild.
  7. Bibliothek & Szenarien: 📚 Bibliothek fügt die NRW-Klassen (Stack, Queue, List, BinaryTree, BinarySearchTree, Graph, DatabaseConnector …) als editierbare Kopie hinzu; Szenarien (oben) lädt fertige Unterrichts-Sätze mit Aufgaben.
  8. SQL: Eine echte SQLite-Datenbank läuft im Browser mit (Tabellen gehege und tier) — über DatabaseConnector wie im Abitur abfragbar. Bei ✓ Übernehmen startet sie frisch.
  9. Speichern & Weitermachen: Die App sichert automatisch auf diesem Gerät. Mit ⬇ Speichern / ⬆ Öffnen wandert das Projekt als Datei (Dateien-App) — für Gerätewechsel, Sicherung und Abgaben.
  10. Abgeben: 📤 Abgabe erzeugt ein fertiges Abgabe-Dokument (Welt-Bild + Quelltext + Konsole) samt Projektdatei und bietet es auf dem iPad direkt zum Teilen an — z. B. nach OneNote oder Teams.
  11. Aufgaben-Links: 🔗 Link packt das aktuelle Projekt komplett in einen Link (für Lehrkräfte: Aufgabe vorbereiten, Link in OneNote einfügen). Links der Form ?szenario=… laden ein Szenario direkt, ?projekt=<URL> eine bereitgestellte Projektdatei.

Echtes Java im Browser

Dein Code wird immer von einem echten Java-Compiler übersetzt und in einer JVM im Browser ausgeführt (CheerpJ) – es geht alles, was Java kann. Nur wenn CheerpJ nicht geladen werden kann (kein Internet, Filter im Schulnetz), springt automatisch ein eingeschränkter Notbetrieb ein, der den typischen Unterrichts-Code direkt ausführt (Methodenaufrufe, new, Zählschleifen, while (laeuft()), return). Oben rechts erscheint dann „erneut versuchen“.
