Klassen-Bibliothek (NRW-Abiturvorgaben)

Fügt eine editierbare Kopie der Klasse zum Projekt hinzu – zum Verwenden, Lesen und (im LK) Verändern. Zum Ausführen wird „Echtes Java“ benötigt.

So arbeitest du mit der JavaWelt

  1. Klassen schreiben: Unten im Quelltext-Bereich. Eigene Figuren-Klassen erben von Figur (public class Biene extends Figur { … }) – mehr Gerüst braucht es nicht.
  2. Übernehmen: ✓ Übernehmen übersetzt deine Klassen. Dabei wird die Welt geleert.
  3. Objekte platzieren: Bei einer Klasse auf neu tippen, dann auf die Welt tippen.
  4. Methoden aufrufen: Objekt antippen – rechts erscheinen seine Methoden mit Eingabefeldern.
  5. Spiel starten: ▶ Start führt deine Weltklasse aus: erst bereiteVor(), dann spiele() mit der Spielschleife while (laeuft()) { … warte(100); }. ■ Stopp beendet die Schleife.
  6. Bilder: Über den 🖼-Knopf bekommt eine Klasse ein Emoji oder eigenes Bild.
  7. Bibliothek & Szenarien: 📚 Bibliothek fügt die NRW-Klassen (Stack, Queue, List, BinaryTree, BinarySearchTree, Graph …) als editierbare Kopie hinzu; Szenarien (oben) lädt fertige Unterrichts-Sätze mit Aufgaben.
  8. Speichern & Weitermachen: Die App sichert automatisch auf diesem Gerät. Mit ⬇ Speichern / ⬆ Öffnen wandert das Projekt als Datei (Dateien-App) — für Gerätewechsel, Sicherung und Abgaben.

Übungsmodus und echtes Java

Ohne den Schalter „Echtes Java“ läuft der Übungsmodus: Er funktioniert sofort und offline, versteht aber nur den typischen Unterrichts-Code (Methodenaufrufe, Variablen mit new, for-Zählschleifen, while (laeuft())). Mit „Echtes Java“ wird dein Code von einem echten Java-Compiler im Browser übersetzt – dann geht alles, was Java kann.
